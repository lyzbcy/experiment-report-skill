# 课程综述与长篇调研报告

先区分教师要求的是实验报告、文献调研综述，还是两者组合。综述不等于实验报告拼接；不用为了满足实验工作流而虚构实验、搭建无关前端或制作假的实验截图。组合任务分别保留各自的证据链。

## 计划并验证实际要求

- 先读教师原始通知和模板，包括封面字段、章节、引用格式、页数范围、图片要求、文件名及提交方式。通过用户明确的追加要求补全验收清单。不要把某次任务的页数或图量要求写成所有报告的默认值。
- 记录选题、文献纳入标准、章节问题、代表性工作与比较维度。对长篇综述先建立内容预算：每小节应回答一个可区分的问题，图表与正文分析相互支持。按主题组织材料，不以放大字号、插入空白或复制内容凑页数。
- 用作者论文、正式出版页、官方资料和公开可复查来源建立文献表。核对作者、题名、年份、链接与正文引用。引用论文结果时保留其适用假设和测量口径；不能跨不同场景直接比较提升比例。预印本标明状态。

## 图与证据分类

- 实测图：由原始实验数据或能够追溯的既有实验汇总生成，说明场景、指标、统计分母及未知；引用旧实验不得声称重新运行。
- 理论曲线或算例：给出公式、参数、单位、取值或构造条件，明确不是实测。图表数值可由脚本重算。
- 文献机制图、流程图、系统结构图：自绘或按许可使用，图注标明文献或作者推导；未部署的设计明确标注建议或示意。
- 配图均有独立编号、题注、来源、正文引用；源图保存可重用版本。检查目标版心上的轴标、图例、字重、颜色、裁切与语义换行。不要将封面校徽、装饰、同一图片重复和无意义截图算作论证图片。
- 只有教师或用户明确提出图量时才按要求计算。以最终 PDF 实际物理页数为分母，平均每10页图数 = 有效图数 × 10 / 总页数；若要求任何连续10页至少有若干图，逐个滑动窗口单独核验。页数不足10页时不要报告连续10页满足要求。表格与图片分开统计，除非需求明确允许合计。

## 学校模板与排版闭环

1. 封面保留正式模板的标识、标题和字段；采用一致宽度的填写列、固定或最小行高，填写值水平/垂直居中，标签不得意外折行。横线可使用单元格底边而非用空格手工对齐。用真实渲染的第一页核对，不以文档 XML 的对齐属性代替视觉。
2. 正文跟随模板字号、正文、版心和行距。长篇综述可以按主题安排分页，但实质内容和图表支撑篇幅。避免空白页、单条参考文献孤页、被拆开的图与图注。
3. 使用原生 Word 公式（OMML）而不是公式图片。检查分数、求和、上下标、序号，以及导出后的显示。图中少量数学符号也要检查字体支持。
4. 更新目录域或在工具确实无法更新时，根据最终 PDF 的分页回写可核验目录；核对每个章节、小节的实际页码及目录显示。记录静态目录需要重新分页后再更新的限制；模板要求活目录时不可用静态目录代替。印刷页码和物理页码不同时区分两者。
5. 同一份终版导出 PDF，逐页目视检查；对修订后的 PDF 再核对受影响页。计算物理页数、正文范围、有效图数、表数、公式数及来源清单，检查实际文件可读、正确命名。报告源稿、图件、最终 PDF 保留至用户验收及提交回执核对。最终报告验收独立于平台提交成功。

## 可选结构核验脚本

使用 Python 3.9+ 和 PyMuPDF（`python -m pip install pymupdf`），对本地 PDF 运行：

```bash
python references/tools/audit_review_pdf.py path/to/report.pdf --manifest path/to/private-manifest.json
```

示例（仅合成占位数据；实际任务按已确认要求填写，带有个人资料的清单只存本地）：

```json
{
  "min_pages": 12,
  "cover": {"page": 1, "values": ["Student A", "00001"], "center_tolerance_pt": 2},
  "headings": [{"page": 3, "text": "1 Introduction"}],
  "toc": [{"page": 2, "text": "1 Introduction", "printed_page": "1"}],
  "figures": [{"id": "figure-1", "page": 3, "caption": "Figure 1 Example", "kind": "raster"}],
  "min_raster_width_px": 300,
  "figures_per_10_pages_min": 0,
  "references": {"start_page": 12, "count": 2}
}
```

可选 `rolling_10_page_min` 是更严格的滑动窗口要求。所有 `page`、`start_page` 为物理页码，`printed_page` 为目录中的印刷页码。脚本按显示的独立文本行核对标题、目录、封面值和唯一图注，匹配式要求目标行不折行；若标题/图注按模板必须跨行，应另外人工核对，不应删除真实图或虚构清单来使检查通过。图件类型 raster 会同时检查该页足够的栅格对象；vector 只核对图注，必须目视确认图实际存在。它不能识别科学内容、图像含义、所有排版缺陷或判断引用是否可靠。输出 `visual_review_required: true`，不能用它代替逐页检查、论文来源核对和用户最终验收。

审查记录要给出满足要求的实际数值和未验证事项。完成后只清理本次临时构建、渲染、贡献打包缓存；发布回流使用合成示例，不上传真实报告、原始材料、身份、账号和作业数据。
