# 学校模板与正式发布

## 查找与适配

1. 优先用作业附件、课程资料区或教师提供的本课程模板。其次查学校、学院和教务官网下载区。走官方来源，核对校名、课程、适用对象与版本。
2. 找不到专用模板时，查对应学校公开的同类报告模板或同校撰写规范及样例，用作版式参考并注明适配依据和差异。校徽从学校官网的标识资料取用。
3. 整份报告按来源核对。检查封面字段和位置、纸型与页边距、正文字体字号、标题层级、段落缩进和行距、目录体例、页眉页脚、分节页码、图表编号与题注。封面字段使用已知信息。学位或其他课程特有的声明、密级、授予信息等按本次任务适配。
4. 无院校或课程要求时使用通用模板，正文默认宋体五号。已有学校模板时，图片、正文和页码跟着模板一起调整，保留模板的可编辑样式和字段。

## 定稿和验收

1. 排版完成后，用可用的 Word 兼容排版工具更新整个目录域及相关页码域并保存。关闭重开，确认目录已有可见条目、页码和可用链接，抽查首尾章及分页变化处。有跨节页码重启时，检查空白页和奇偶页设置。
2. 参考同一份定稿数据导出 PDF，用于正式提交。优先从终版 Word 导出。如果 PDF 独立排版，按 PDF 自己的实际分页生成并复核目录。检查无试用水印和缺字，图注与图在一起。将 Markdown、Word、PDF 与截图和运行结果交叉核对。
3. 按平台要求打包。平台要求源代码和报告一起提交时，保留源码、运行材料和 PDF，按要求命名。交付时提供可直接打开的 PDF，Word 和 Markdown 用于后续编辑。
4. 若排版工具只能生成带试用水印的预览，预览仅供内部验收。无法完成目录更新或无水印 PDF 时，明确该环节待完成。

## 心得感悟

沿着“看到的现象 → 定位和改动 → 验证结果”写一个真实细节。比如真实截图检查确实发现视口太短，就写哪张图、末尾缺了什么、改完怎么确认。自然收尾可写“这次实验挺有意思的”或“下次想试试……”，根据本人确认的感受和项目内容自然使用。没有发生的错误、试错和个人经历留空或请本人补充。
